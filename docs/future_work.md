# Future work after the experiment freeze

The following ideas are intentionally deferred rather than added after observing the main results:

- Evaluate more independent seeds to narrow the wide three-seed confidence intervals.
- Study sensitivity to the operational-risk weight instead of tuning it on the frozen target test set.
- Compare alternative operational-risk proxies and calibrated ensemble uncertainty.
- Investigate balance-preserving or feasibility-aware surrogate architectures.
- Report tolerance-sensitivity analyses for raw feasibility while retaining the frozen primary tolerance.
- Compare alternative repair formulations and operating-condition distributions on new frozen datasets.
- Test the acquisition rules on larger standard power-system networks.
